# SAÉ 1.04 - Conception et mise en place d'une base de données

## Présentation du projet
Ce projet a été réalisé dans le cadre de la SAÉ 1.04 lors de notre première année de BUT Informatique. L'objectif de cette ressource était de concevoir et d'implémenter une base de données relationnelle complète répondant aux besoins de gestion d'une organisation, en l'occurrence un club de voile.

## Objectifs pédagogiques
Ce projet a permis de mettre en pratique les notions fondamentales de la gestion de données et des systèmes d'information :
* Analyse des besoins d'un client et définition des règles de gestion métier.
* Modélisation des données via la réalisation d'un Modèle Conceptuel de Données (MCD / Entité-Association).
* Passage au Modèle Relationnel de Données (MRD) avec la définition des clés primaires et étrangères.
* Écriture de scripts SQL pour la création des tables, l'application des contraintes d'intégrité, et l'insertion d'un jeu d'essai pertinent.
* Formulation de requêtes SQL complexes pour extraire des informations utiles à la prise de décision.

## Contenu du projet
L'archive regroupe l'ensemble des livrables conceptuels et techniques :
* Les documents d'analyse comprenant le dictionnaire de données et les règles de gestion.
* Les modélisations graphiques (MCD et MRD).
* Les scripts SQL (`.sql`) contenant la structure des tables (DDL) et le jeu de données initial (DML).
* Le dossier ou rapport listant les requêtes d'extraction demandées pour répondre aux besoins opérationnels du club (gestion des adhérents, suivi des réservations de matériel, planification des cours, etc.).

## Utilisation
Pour déployer et tester cette base de données, vous devez utiliser un Système de Gestion de Base de Données (SGBD) relationnel (tel que PostgreSQL, MySQL ou Oracle).

1. Ouvrez l'interface ou le terminal de votre SGBD.
2. Exécutez le script SQL de création pour générer la structure des tables et insérer les données d'essai.
3. Utilisez le fichier de requêtes pour tester les différentes extractions et analyses de données fournies.
