# SAÉ 1.01 - Jeu textuel "World of IUT"

## Présentation du projet
Ce projet a été réalisé dans le cadre de la SAÉ 1.01 lors de notre première année de BUT Informatique. Il s'agit de "World of IUT", un jeu d'aventure textuel interactif développé entièrement en langage C. Le jeu se déroule exclusivement en ligne de commande (console) et invite le joueur à explorer un environnement défini, interagir avec des éléments et accomplir des objectifs.

## Mécaniques de jeu
Dans "World of IUT", le joueur évolue à travers différentes pièces d'un bâtiment (l'IUT). Les mécaniques principales incluent :
* L'exploration de différentes salles connectées entre elles.
* La collecte et l'utilisation d'objets présents dans l'environnement.
* L'interaction textuelle via un système de commandes interprétées par le programme.

## Comment jouer ?
Contrairement à un projet web, ce jeu ne nécessite pas de connexion internet et s'exécute localement.
Pour lancer une partie, il vous suffit de double-cliquer sur le fichier exécutable (`.exe`) présent dans les dossiers du projet. Le jeu s'ouvrira directement dans un terminal de commande.

## Architecture technique
Ce projet a été l'occasion de mettre en pratique les fondamentaux de l'algorithmique et de la programmation procédurale. Le code a été pensé pour être modulaire, lisible et maintenable.
L'architecture repose sur plusieurs structures de données essentielles :
* Gestion du **Joueur** (inventaire, position actuelle).
* Gestion des **Salles** (descriptions, portes, connexions).
* Gestion des **Objets** (ramassables, utilisables).

## Contenu de l'archive
* Le code source du jeu développé en langage C.
* L'exécutable (`.exe`) permettant de lancer le jeu sous Windows.
* Le plan du jeu ("Plan maison World Of IUT.pdf"), qui sert de carte pour se repérer dans les différentes salles.
