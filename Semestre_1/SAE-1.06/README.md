# SAÉ 1.06 - Étude d'une organisation : OpenAI

**Lien vers le site fonctionnel :** [https://openai-sae.netlify.app/](https://openai-sae.netlify.app/)

## Présentation du projet
Ce projet a été réalisé dans le cadre de la SAÉ 1.06 de notre première année de BUT Informatique. L'objectif principal était de mener une analyse stratégique et organisationnelle complète d'un acteur majeur du numérique, puis de restituer nos recherches sous la forme d'un site web professionnel. Notre choix d'étude s'est porté sur OpenAI.

## Contenu de l'étude
À travers les différentes pages du site, nous avons décortiqué plusieurs aspects stratégiques de l'entreprise :
* L'analyse de l'environnement macro-économique via la matrice PESTEL.
* L'analyse des forces, faiblesses, opportunités et menaces (SWOT).
* L'étude approfondie de la concurrence sur le marché très dynamique de l'intelligence artificielle.
* Les engagements et les enjeux liés à la RSE (Responsabilité Sociétale des Entreprises).

## Composition de ce dépôt
Ce dépôt regroupe l'ensemble des ressources, maquettes et fichiers de code produits durant cette SAÉ :
* Le code source complet du site web statique.
* Le dossier des assets contenant l'ensemble des médias utilisés (logos OpenAI, DALL-E, Sora, portraits de l'équipe dirigeante comme Sam Altman, etc.).
* Le document de conception et les maquettes réalisées sur Figma, qui nous ont permis de structurer l'expérience utilisateur avant le développement.

## Outils et technologies
* Développement : Web classique (HTML, CSS).
* Prototypage visuel : Figma.
* Déploiement : Netlify.
