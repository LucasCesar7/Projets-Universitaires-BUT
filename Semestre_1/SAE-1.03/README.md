# SAÉ 1.03 - Installation et configuration d'un poste de travail

## Présentation du projet
Ce projet a été réalisé dans le cadre de la SAÉ 1.03 lors de notre première année de BUT Informatique. L'objectif principal était d'étudier, de comparer et de mettre en place des environnements d'exploitation afin de configurer un poste de travail optimisé et dédié au développement informatique.

## Objectifs pédagogiques
Cette SAÉ nous a permis de plonger dans l'administration système de base et de comprendre l'architecture des systèmes d'exploitation :
* Réalisation d'une étude comparative entre différents systèmes (notamment Windows et plusieurs distributions Linux).
* Installation de systèmes d'exploitation en environnement physique et virtualisé (utilisation d'outils comme VirtualBox).
* Configuration post-installation : gestion des utilisateurs, des permissions, partitionnement et configuration réseau de base.
* Déploiement d'un environnement de développement complet et fonctionnel pour un profil de programmeur.

## Contenu du projet
L'archive de ce projet regroupe les éléments documentaires et techniques produits lors de cette étude :
* Le rapport d'étude comparative détaillant les avantages, les inconvénients et les cas d'usage des différents systèmes d'exploitation testés.
* Les documentations techniques et guides d'installation pas-à-pas que nous avons rédigés.
* Les éventuels scripts de configuration (Bash/Batch) utilisés pour automatiser la mise en place de l'environnement de développement.

## Utilisation
Ce projet étant principalement orienté sur l'administration système et la documentation, il n'y a pas d'exécutable direct à lancer. 
Pour explorer le travail réalisé, nous vous invitons à :
1. Consulter les rapports et documentations techniques au format PDF pour comprendre nos choix d'architecture.
2. Analyser les scripts de configuration fournis dans les dossiers correspondants. Si vous souhaitez les tester, assurez-vous de les exécuter dans un environnement sécurisé ou une machine virtuelle (VM) pour ne pas altérer votre système hôte.
