# SAÉ 2.03 - Installation de services réseaux

## Présentation du projet
Ce projet a été réalisé dans le cadre de la SAÉ 2.03 lors de notre première année de BUT Informatique à l'IUT de Saint-Dié-des-Vosges. L'objectif principal de cette ressource était de comprendre, d'installer et de configurer des services réseaux fondamentaux sur un système d'exploitation Linux (distribution Ubuntu). 

Notre étude s'est particulièrement concentrée sur le déploiement du serveur web Apache et sur la compréhension de l'architecture client-serveur.

## Objectifs pédagogiques
Cette SAÉ nous a permis d'aborder des concepts clés de l'administration réseau et système :
* Appréhender le modèle client-serveur et le protocole HTTP/HTTPS.
* Installer le paquet `apache2` dans un environnement Linux.
* Administrer et modifier les fichiers de configuration du serveur web (notamment la directive `DocumentRoot`).
* Gérer les droits et permissions des répertoires et utilisateurs sous Linux (ex: utilisateur `www-data`, commandes `chown`, `chmod`).
* Déployer et tester une arborescence web personnalisée (par exemple, basculer la racine vers `/home/dev/www`).

## Contenu du projet
L'archive de ce dépôt contient l'ensemble des livrables techniques et théoriques réalisés au cours de cette SAÉ :
* Le rapport détaillant l'architecture client-serveur, accompagné de schémas explicatifs.
* Le document des livrables techniques expliquant pas-à-pas les commandes et les modifications de configuration effectuées sur le serveur.
* Le cahier des charges et l'énoncé du projet.


## Utilisation
Ce projet se concentrant sur l'administration d'un serveur, vous ne trouverez pas d'application exécutable classique, mais plutôt des guides de configuration et des ressources documentaires.

Pour explorer notre travail, vous pouvez :
1. Lire les documents Word et PDF pour comprendre la théorie derrière les requêtes HTTP et le fonctionnement d'Apache.
2. Si vous disposez d'une machine virtuelle sous Ubuntu, vous pouvez suivre les étapes de nos rapports pour reproduire la configuration du serveur web sur votre propre environnement local.
