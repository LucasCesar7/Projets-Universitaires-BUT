# SAÉ 2.04 - Modélisation et exploitation d'une base de données

## Présentation du projet
Ce projet a été réalisé dans le cadre de la SAÉ 2.04 lors de notre première année de BUT Informatique. L'objectif principal de cette ressource était de mettre en place, de remplir et d'exploiter une base de données relationnelle complexe pour une organisation, en se concentrant sur le cas d'étude d'un supermarché. 

Au-delà de la simple gestion technique, ce projet visait à extraire de la valeur à partir des données pour produire des analyses utiles aux décideurs et utilisateurs non-informaticiens.

## Objectifs pédagogiques
Ce projet a permis de consolider et d'approfondir les compétences en gestion de bases de données et en informatique décisionnelle :
* Conception et compréhension fine des schémas relationnels (tables, clés primaires, clés étrangères et contraintes d'intégrité).
* Manipulation de volumes de données réalistes à travers l'écriture de scripts d'insertion massifs (fichiers de remplissage de la base).
* Formulation de requêtes SQL avancées et complexes (jointures multiples, fonctions d'agrégation, regroupements, sous-requêtes) pour répondre à des problématiques métiers précises.
* Restitution et vulgarisation des résultats sous forme d'analyses claires, lisibles et exploitables par la direction de l'organisation.

## Contenu du projet
L'archive de ce dépôt comprend l'ensemble des livrables techniques liés à la base de données du supermarché :
* Les scripts SQL de création des tables et de définition des contraintes.
* Les fichiers et documents de remplissage de données (scripts `INSERT` volumineux pour constituer un jeu d'essai réaliste).
* Le recueil des requêtes SQL d'extraction et d'analyse de données.
* Les rapports de synthèse ou documents d'analyse interprétant les résultats des requêtes pour les utilisateurs métiers.

## Déploiement et Utilisation
Pour exécuter les scripts et tester les requêtes de ce projet, vous devez disposer d'un Système de Gestion de Base de Données (SGBD) relationnel.

1. Connectez-vous à votre serveur de base de données ou utilisez un outil d'administration graphique.
2. Exécutez le script de structure pour créer les tables du supermarché.
3. Exécutez le script d'insertion (contenant les lignes `INSERT`) pour peupler la base de données avec le jeu d'essai.
4. Lancez les requêtes d'analyse pour observer les résultats d'extraction de données.
